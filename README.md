# R.A.V.E.N. Core

**Robotic Autonomy, Vision & Engineering Network**

RAVEN Core v1.0.0 is complete. This repository is a public project overview; source code and implementation details remain private.

## Current components

- Piper TTS voice
- Flask HUD
- Computer vision / YOLO
- Learning and mission foundations for autonomous robotics

## System role

R.A.V.E.N. is the software and autonomy layer being developed for SCRAPYARD Labs robotic platforms. RAVEN Core v1.0.0 provides the current foundation for:

- Voice interaction through Piper TTS
- Operator visibility through a Flask HUD
- Computer-vision work using YOLO
- Learning and mission foundations for autonomous robotics

## Platform research

W.R.A.I.T.H. is the current custom mobile platform associated with this work. Its camera/YOLO vision work is under active development.

SCRAPYARD Labs’ future research direction is to evaluate R.A.V.E.N. and dimOS across two very different platforms: the custom W.R.A.I.T.H. rover and a prospective Unitree Go2 platform. This is proposed work; no completed cross-platform integration or testing results are claimed.

Planned work is labeled as planned. This repository does not claim completed platform integrations, testing results, sponsors, or partnerships.
