# R.A.V.E.N. Core

**Robotic Autonomy, Vision & Engineering Network**

RAVEN Core v1.0.0 is complete. This repository is a public project overview; source code and implementation details remain private.

## Current components

- Piper TTS voice
- Flask HUD
- Computer vision / YOLO
- Learning and mission foundations for autonomous robotics

## Research direction

RAVEN Core is being developed for autonomous robotics work across multiple platforms. Its current project context includes SCRAPYARD Labs' W.R.A.I.T.H. rover. A future proposal is to evaluate R.A.V.E.N. and dimOS across W.R.A.I.T.H. and a prospective Unitree Go2 platform.

Planned work is labeled as planned. This repository does not claim completed platform integrations, testing results, sponsors, or partnerships.
